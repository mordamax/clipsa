Privacy policy

Effective date: 8 November 2026

In short: Clipsa collects nothing. Your clipboard history stays on your device and is encrypted. There are no accounts, analytics, telemetry or crash reports. The app only goes online if you turn on update checks, and then it only talks to GitHub Releases. This website uses no cookies and no trackers.

This policy covers the Clipsa desktop app for macOS, Windows and Linux and this website. Clipsa is free, open-source software under the MIT license, and you can check every statement below against the source code.

What we collect

Nothing. The Clipsa project does not run any server that receives data from the app or from this website. We have no way to see what you copy, how you use Clipsa, or who you are.

Data the app stores on your device

  • Clipboard history. Clipsa records what you copy (text, rich text, images and file lists) so you can paste it again. It is stored only on your computer, in clipsa/clipboard.db inside your data directory:
    • macOS: ~/Library/Application Support
    • Windows: %APPDATA%
    • Linux: $XDG_DATA_HOME, or ~/.local/share if it is not set
  • Encryption. The content of every item is encrypted individually with AES-256-GCM before it is written to disk. Metadata such as content type, size and the times an item was created and last used is not encrypted.
  • Encryption key. A random key is created on first run and kept in your operating system's keychain: the macOS Keychain, Windows Credential Manager, or the Secret Service on Linux (for example GNOME Keyring or KWallet). It never leaves your device.
  • Settings. Your preferences are stored locally and are not encrypted.
  • Things Clipsa avoids storing. On macOS and Windows, copies that password managers mark as concealed or transient are skipped, and you can exclude specific apps. On Linux these signals are not available; you can pause monitoring from the tray.

You control this data. You can delete single items, clear your history (pinned items are kept until you unpin or delete them), set a maximum number of items, and have items deleted automatically after a number of days.

No accounts, analytics or telemetry

Clipsa has no user accounts and no sign-in. It contains no analytics, telemetry, advertising or crash reporting, and it does not sync your history anywhere.

Network access: the optional update check

The only network request Clipsa can make is the update check. It is off until you opt in on the first-run screen, and you can change it at any time in Settings.

When it is on, Clipsa downloads a small version file (latest.json) from GitHub Releases at startup and once a day while it runs, and, if you install an available update (or turn on automatic installation), the update package. Updates are verified against a signing key built into the app before they are installed. Clipsa sends no clipboard data or settings with these requests. Like any web server, GitHub receives your IP address and the request's user agent; their handling is described in the GitHub General Privacy Statement.

This website

This website is a set of static pages hosted on Vercel. It sets no cookies, runs no scripts, and loads no fonts, images or other resources from third parties. There are no analytics or trackers (Vercel Web Analytics is not enabled).

Vercel, as the host, processes visitors' IP addresses and request details to serve the pages and protect against abuse. This is covered by the Vercel Privacy Policy. The Clipsa project does not use these logs.

Downloads and third-party services

Clipsa installers are published on GitHub Releases, and Clipsa can also be installed with Homebrew. Downloads from these services are governed by their own policies: the GitHub General Privacy Statement and Homebrew's analytics documentation. If you buy Clipsa from the Mac App Store, Apple handles the purchase and updates under its own terms and privacy policy; the app itself behaves the same and collects nothing. If you sponsor the project through GitHub Sponsors, GitHub processes that payment under its own terms.

Children

Because Clipsa collects no personal data from anyone, it collects none from children either.

Changes to this policy

If this policy changes, the updated version will be published on this page with a new effective date, and the change will be noted in the release notes of the next Clipsa version on GitHub Releases.

Contact

Questions about privacy can be asked in GitHub issues. To report a security vulnerability, please use a private GitHub security advisory instead of a public issue.
