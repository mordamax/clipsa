The private clipboard manager

Clipboard history that stays private

Clipsa remembers what you copy so you can find it and paste it again from the keyboard. Your history stays on your device, every item is encrypted, and nothing is sent anywhere.

How it works

Copy. Summon. Paste.

No new habits. Copy as you always do; Clipsa keeps it, and a shortcut brings it back in any app.

  1. 1
    ⌘C

    Copy as usual

    Text, rich text, images and files are saved to your history, encrypted, as you copy them.

  2. 2
    ⌘⇧V

    Open the picker

    Press Cmd/Ctrl + Shift + V anywhere. Type a few letters to filter.

  3. 3
    ↵

    Paste it back

    Enter pastes into the app you were using. Shift + Enter pastes the other way: plain text or formatted.

Privacy

Built like a vault, not like a cloud service

You copy passwords, addresses, messages and work you have not shared yet. A clipboard manager stores all of it, so Clipsa keeps it on your device and unreadable to anyone else.

  • Encrypted by default

    Each item is encrypted individually with AES-256-GCM before it is written to disk, with nothing to set up. The key is kept in your OS keychain, not next to the data, and history lives in a local database: no account, no server, nothing to upload.

    A plain-text history file

    API_KEY=sk_live_51Hx9Q… Recovery code: 4F7K-9QPL Meet me at 14 Elm Street IBAN DE89 3704 0044 05…

    Clipsa's database

    q9Xv2+LmR0aT8fKc1Zp… Hc7Wb0eY4uN+Qd3sJk… 0rTzP5gA9mVx/Le2Uy… Kb6NwQ1o+Fh8sXr3Di…

  • Password copies skipped

    Copies that password managers mark as concealed or transient are never recorded (macOS and Windows). You can also exclude whole apps.

  • App lock

    Require Touch ID or your login password (macOS) or Windows Hello to see your history after Clipsa has been in the background.

  • No network by default

    No requests unless you opt in to update checks. No telemetry, analytics or crash reporting.

  • Deleted means overwritten

    The database runs with secure delete, so removed items are overwritten instead of lingering in free space.

  • Open source

    All of the code is on GitHub under the MIT license, and the security model is documented, including its limits.

Why encrypt, if password copies are skipped?

Skipping only catches copies that a password manager explicitly marks as secret. Most sensitive things people copy carry no such mark, so a clipboard history slowly becomes a months-long log of them.

Skipped automatically

  • A password from 1Password or Bitwarden (macOS and Windows)
  • Copies from apps you exclude (macOS and Windows)

Still saved, so encrypted

  • A password from Notes, a chat or a text file
  • 2FA and recovery codes
  • API keys and tokens from a terminal or dashboard
  • Seed phrases, card numbers, bank details
  • Private messages, addresses, medical or legal text

Encryption keeps that log unreadable when the database file leaves Clipsa's hands: in Time Machine or cloud backups, on an unencrypted backup drive, when malware or a sync tool copies app data folders, or when another administrator account reads your files. Without the key from your keychain, the file is noise.

Limits. Item contents are encrypted; metadata such as content type, size and timestamps, and your settings, are not. Clipsa protects history at rest, such as a copied or backed-up database file. It is not a sandbox against malware: code running as your user while you are logged in can read the clipboard directly.

Features

Everything you copied, one shortcut away

A fast, keyboard-first history for everything you copy, with the pieces you reuse kept close.

Quick picker

Find it in a few keystrokes

Press Cmd/Ctrl + Shift + V in any app. Type a few letters and Enter pastes the item straight into the app you were using.

  • Pinned items and snippets come first.
  • Shift + Enter pastes as plain text; Cmd/Ctrl + 1–9 pastes one of the first nine items.
  • The hotkey is configurable, or you can turn it off.

Pinned items & snippets

Keep what you paste every day

Pin anything to keep it forever. Pinned items are exempt from retention and "Clear history". Give them a name, or write reusable text snippets for sign-offs, links and templates.

  • Named items show their title in the picker.
  • Edit a snippet's text and title in place.

Rich content

Text, rich text, images and files

Rich text keeps its HTML and plain-text versions, images are stored as PNG and file copies as their paths. Copying an item again restores its original format.

  • Search the text and titles of your history.
  • Filter by content type.

App lock

Locked when you step away

Require Touch ID or your login password (macOS) or Windows Hello to see history after Clipsa has been in the background for a time you choose. Capture keeps running while locked.

  • Locks the history window and the quick picker.
  • Lock as soon as Clipsa is hidden, or after a delay you choose.

  • Paste as plain text

    Strip formatting with Shift + Enter, or make plain text the default.

  • Search and filter

    Search the text and titles of your history and filter by content type.

  • Retention limits

    Cap the number of items and delete items after a number of days, checked after every capture and hourly.

  • Per-app exclusions

    Never record copies from an app: by bundle id on macOS (com.agilebits.onepassword7) or exe name on Windows (keepass.exe).

  • Launch at login

    Optional. Lives in the tray with Open, Pause/Resume monitoring and Quit.

  • Light and dark themes

    Light, dark or follow the system, plus a compact mode for a denser list.

  • Updates with release notes

    Opt-in update checks show what's new before you install. Updates are verified against a signing key built into the app.

  • Keyboard-first

    ↑ ↓ to move, Cmd/Ctrl + 1–9 to paste one of the first nine, Tab to switch the type filter, Cmd/Ctrl + C to copy without pasting, Cmd/Ctrl + , for Settings, Esc to close.

FAQ

Questions, answered

Something missing? Ask in GitHub issues.

Is Clipsa free?

Yes. The download from this site is free and open source under the MIT license, with every feature, no trial and no account. A paid Mac App Store edition is coming as an optional way to support the project; it has the same features, except that App Store rules don't let it paste into other apps for you.

Does Clipsa send my data anywhere?

No. Your clipboard history never leaves your computer. Clipsa has no telemetry, analytics or crash reporting.

The only network request Clipsa can make is the update check, and it is off until you opt in on the first-run screen or in Settings. When enabled, Clipsa asks GitHub Releases for the latest version at startup and once a day. See the privacy policy.

How is my history encrypted?

Each item's content (text, HTML, image bytes, file paths) is encrypted with AES-256-GCM using a fresh random 96-bit nonce. A random 256-bit master key is generated on first run and stored in your OS keychain. Duplicates are detected with HMAC-SHA256 under a key derived from the master key, so the database holds no plain hash of your content.

If keychain access is denied or fails, Clipsa shows an error and refuses to start. It never silently creates a new key, because that would make your existing history unreadable.

Not encrypted: content type, size, timestamps and settings. Read the full security model.

What about passwords?

On macOS and Windows, Clipsa skips copies that password managers mark as concealed, transient or auto-generated. This is on by default. You can also exclude apps so nothing copied while they are in front is recorded.

Linux does not expose these markers or the app that made a copy. There, use Pause monitoring from the tray, or delete the item afterwards.

Why does macOS ask for Accessibility permission?

Pasting into another app means simulating Cmd + V, and macOS only allows that for apps with the Accessibility permission. Clipsa needs it only for pasting from the quick picker; capturing your clipboard does not need it.

Grant it in System Settings → Privacy & Security → Accessibility, or let Clipsa request it from its Settings. Until then, copy an item from the history window and paste it yourself.

Where is my history stored?

In clipsa/clipboard.db inside your data directory: ~/Library/Application Support on macOS, %APPDATA% on Windows and $XDG_DATA_HOME (or ~/.local/share) on Linux.
